# GhostType – Keyboard Type Test

A typing test with a **ghost cursor** you race against. Paste any paragraph, set the ghost's WPM, and see detailed stats.

Live: https://cameronjtoy.github.io/Keyboard-Type-Test/

## Features
- Paste your own text; ghost cursor types it at an adjustable WPM (slider, presets, or live +/− during a run)
- Live WPM, accuracy, time, progress and lead/lag versus the ghost
- Results: net & raw WPM, accuracy, consistency, peak WPM, mistakes, backspaces, slowest words, most-missed keys, WPM-over-time chart, win/lose vs ghost
- Option to block typing past a mistake; run history stored locally

WPM uses the standard 5 characters = 1 word. Esc restarts. Ctrl/Cmd+Enter starts from the text box.

No build step: open `index.html`. Deployed with GitHub Pages via `.github/workflows/pages.yml`.
